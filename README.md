# Visual Timer

A responsive focus timer built with React and Vite. It combines an interactive rotary dial with countdown, Pomodoro, interval, and stopwatch modes.

## Features

- Custom durations, quick adjustments, and reusable presets
- Focus history, statistics, and shareable timer links
- Theme and light/dark appearance controls
- Optional sound effects, completion alarms, and browser notifications
- Keyboard shortcuts and fullscreen mode
- Installable PWA with offline support

## Requirements

- Node.js 18 or newer
- npm

## Develop

```bash
npm ci
npm run dev
```

## Build and preview

```bash
npm run build
npm run preview
```

Vite writes the static production site to `dist/`. Deploy the contents of that directory at the root of an HTTPS-enabled static host to enable the service worker and browser notifications.
